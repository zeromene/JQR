# JQR 固定预算扫描：推理前冻结方案

2026-11-17（北京时间）。用户授权在 Qwen 和 Phi 上执行此前讨论的预算扫描。

## 固定问题与范围

沿用 HotpotQA-1,400 与 MuSiQue-535，共 1,935 题。所有题在四个预先指定的 Qwen 证据 token 预算 128/256/384/512 上评估。每题、每预算比较两种现有生产策略：JQR（quote_anchor）和全候选完整句重排序装包（strong_rerank）。两位读者为 Qwen3.5-9B、Phi-4-mini-instruct，共 30,960 个逻辑条件。

每个预算 B 是外部固定上限，绝不由 JQR 实际长度决定。重排序直接在 B 下使用现有生产装包。JQR 按现有算法重新计算全局参考、有效上限 L、锚点及回退，再尝试完整引文集合接纳；失败则使用该预算下的正常回退。不得截短旧的 512-token 文本、切句、填充、排除回退题或改动提案。若没有完整句可装入，记录构造失败，保留总体分母。

历史回退函数的实验臂名称校验仅登记旧预算。新适配器保留原构造函数字节码，仅在隔离的函数全局环境中扩展名称校验至本轮四个预算；不改原模块。256/512 单元测试复现原装包，512 在全部真实题上再次逐项核对。

问题、原文、提案、检索路径、排序分数、渲染器、读者提示、模型权重、BF16/SDPA、贪婪解码和输出上限固定。提案不含预算条件，故完全复用，不新增提案或重排调用。Phi 读取相同 Qwen 预算下的证据；另外报告 Phi 实际 token 数，不声称 Phi 的 token 上限相同。

本轮是既有面板上的补充条件分析，不是新的独立复现，也不替换原论文任何主要检验。不要求四个预算全部显著，更不预设“越紧越好”。不扩样、不加预算点、不按结果调方法。

## 复用与推理

先冻结方案、代码和原始材料身份。用完整请求（模型、完整消息、输出上限）及冻结的模型/推理身份复用父确认实验、组件对照、引文对照及紧凑重排实验缓存。对每个被复用输出校验请求身份、来源签名、prompt token 数和文件哈希；失败输出也按同样规则复用。

512 点逐题复现父确认实验的 JQR 和 strong_rerank 文本、状态与完整请求；它不复用表 4 的 E 臂作为完整预算基线。低预算请求跨预算或跨方法相同的只推理一次。全部 30,960 份逻辑材料和映射冻结后才运行新增读者推理，不在中途评分。

两位读者先 Phi 后 Qwen，沿用原全 GPU BF16/SDPA 运行方式。GPU 共享锁入场；Phi 需 12,000 MiB，Qwen 需 26,000 MiB，显存不足持续等待，无排队和运行到期时间。明确 OOM 留痕后继续排队；其他未知中断保留现场并停止，不静默重试，不终止其他任务。

## 统计与输出

完整矩阵完成后统一使用原官方 F1/EM 评分，失败保留零分及全部分母。512 点逐项复现父实验两方法、两读者的 7,740 个 F1/EM。

报告每个数据集×读者×预算的两方法绝对 F1/EM、配对差值、有效率、证据实际长度及完整 reader prompt token。JQR 另按数据集×预算报告接纳率、回退原因与有效上限分布。相同构造的两位读者不重复解释为独立样本。

沿用来源组件聚类、question-weighted bootstrap，种子 30，10,000 次；同一次组件重采样同时用于两位读者和四个预算。报告所有 16 个 F1 差值的普通 95% 区间，以及整个 16 项族的 bootstrap max-standardized-deviation 同时 95% 区间；EM 报普通区间作为次要指标。

预算依赖直接检验同题增益差 Δ(B)−Δ(512)，B=128/256/384，构成 12 项单独的交互对比族，也报告普通区间和族内同时 95% 区间。使用 bootstrap 各列标准差标准化，零方差列给出点区间。不能凭某点显著、另一点不显著就声称预算交互成立，也不把未显著解释为等效。

同时列出双方均正常有效回答的敏感性结果，明确子集分母；它不取代全量结果。曲线用于呈现固定预算下的整体策略表现，不单独隔离纯保留因果效应。实际长度与接纳率帮助解释曲线，但不把引文包含关系当成语义完整性。

最终输出固定预算结果表、预算交互表、接纳/回退表和可重画的 PDF 曲线；不自动修改论文。无新训练，无新增文献基线，无额外模型调参。
